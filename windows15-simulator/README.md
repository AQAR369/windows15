# Windows 15 Vision Simulator (App Package)

This directory contains the Vite + React + TypeScript application that powers the Windows 15 concept desktop. It is generated from the Vite starter template and expanded with custom UI, window management, and animation layers.

- `npm run dev` - start the local development server (http://localhost:5173)
- `npm run build` - create a production build in `dist/`
- `npm run preview` - preview the production build
- `npm run lint` - run ESLint with the provided configuration

For a high-level overview, feature list, and project tour, see the root [`README.md`](../README.md).
